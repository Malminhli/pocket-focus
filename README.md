# Pocket Focus

مؤقت تركيز بسيط وأنيق يعمل بالكامل داخل المتصفح، ويدعم العربية والإنجليزية.

![Pocket Focus preview](https://dummyimage.com/1200x630/171816/d9f36a&text=Pocket+Focus)

## لماذا هذا المشروع؟

أداة صغيرة تساعدك على بدء جلسة تركيز دون تسجيل دخول أو إعدادات معقدة. اختر نوع الجلسة، ابدأ المؤقت، وتابع عدد جلساتك اليومية.

## المزايا

- مؤقت Pomodoro: تركيز 25 دقيقة، استراحة قصيرة 5 دقائق، واستراحة طويلة 15 دقيقة.
- تبديل فوري بين العربية والإنجليزية مع دعم RTL.
- حفظ عدد جلسات التركيز في `localStorage`.
- تصميم متجاوب يعمل على الجوال والكمبيوتر.
- بدون أطر عمل أو اعتماديات؛ HTML وCSS وJavaScript فقط.

## التشغيل محليًا

لا يحتاج المشروع إلى تثبيت. افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
```

ثم افتح <http://localhost:8000>.

## النشر

يمكن نشره مباشرة عبر GitHub Pages من إعدادات المستودع: **Settings → Pages → Deploy from a branch → main → / (root)**.
